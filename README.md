# Marid · مارد

**Marid** is an AI assistant for Android by [BLRT.ai](https://blrt.ai): genies that chat, use your phone, code, design and make pictures, video and audio, with your own AI keys or models that run on the phone.

This repository is where Marid is published:

- **Releases:** the Android app (APK) and its signed update files: newer on-device engines, instruction packs and the genie and skill catalog.
- **`index.json`** (attached to each release): the signed list Marid reads to offer updates. Marid installs nothing that isn't signed by BLRT.ai, and Android asks you before installing a new version.
- Source archives that some components' licences ask us to publish next to the app.

The same files are mirrored on Hugging Face.
